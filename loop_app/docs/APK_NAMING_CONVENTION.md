# APK 命名规范

## 1. 命名规则概述

### 1.1 基本格式
```
{程序名}_{状态类型}_{版本号}_{构建日期}_{构建序号}.apk
```

### 1.2 命名示例
```
Loop_release_1.0.0_20260326_01.apk
Loop_beta_0.0.1_20260326_02.apk
Loop_fix_0.0.2_20260326_01.apk
Loop_feature_0.0.3_20260326_01.apk
```

## 2. 命名元素详解

### 2.1 程序名
- **固定值**：`Loop`
- **说明**：应用程序的名称

### 2.2 状态类型

| 状态类型 | 英文标识 | 中文说明 | 使用场景 | 完整性 |
|---------|---------|---------|---------|--------|
| 正式版 | `release` | 正式发布版本 | 经过完整测试，功能完整，可用于生产环境 | ✅ 完全体 |
| 测试版 | `beta` | 公开测试版本 | 功能基本完整，需要用户反馈测试 | ⚠️ 非完全体 |
| 内测版 | `alpha` | 内部测试版本 | 功能开发中，仅限内部测试 | ❌ 非完全体 |
| 候选版 | `rc` | 候选发布版本 | 准备发布前的最终测试版本 | ✅ 接近完全体 |
| 修复版 | `fix` | 问题修复版本 | 针对正式版的问题修复 | ✅ 完全体 |
| 紧急修复 | `hotfix` | 紧急修复版本 | 针对严重问题的紧急修复 | ✅ 完全体 |
| 功能版 | `feature` | 新功能版本 | 包含新功能开发的版本 | ⚠️ 非完全体 |
| 开发版 | `dev` | 开发中版本 | 日常开发过程中的构建 | ❌ 非完全体 |
| 调试版 | `debug` | 调试版本 | 用于调试的构建版本 | ❌ 非完全体 |

### 2.3 版本号
- **格式**：`{主版本}.{次版本}.{修订版本}`
- **规则**：遵循语义化版本控制（Semantic Versioning）
- **来源**：从 `pubspec.yaml` 文件中的 `version` 字段读取
- **示例**：`1.0.0`、`1.0.1`、`1.1.0`、`2.0.0`

#### 版本号递增规则
- **主版本**：不兼容的 API 修改
- **次版本**：向下兼容的功能性新增
- **修订版本**：向下兼容的问题修正

### 2.4 构建日期
- **格式**：`YYYYMMDD`
- **说明**：APK 构建的日期，便于追溯
- 示例：`20260326` 表示 2026 年 3 月 26 日

### 2.5 构建序号
- **格式**：两位数字，从 `01` 开始
- **说明**：当天第几次构建，便于区分同一天的不同构建
- **示例**：`01`、`02`、`03`

## 3. 版本号管理规范

### 3.1 版本号格式
```
{主版本}.{次版本}.{修订版本}+{构建号}
```

### 3.2 版本号管理策略

#### 正式发布前版本号策略
- **策略**：在正式发布前，版本号格式为 `0.0.x`
- **示例**：
  - 开发版：`Loop_dev_0.0.0_20260326_01.apk`
  - 测试版：`Loop_beta_0.0.1_20260326_01.apk`
  - 修复版：`Loop_fix_0.0.2_20260326_01.apk`

#### 正式发布后版本号递增规则
- **主版本递增**：不兼容的 API 修改，如 `1.0.0` → `2.0.0`
- **次版本递增**：向下兼容的功能性新增，如 `1.0.0` → `1.1.0`
- **修订版本递增**：向下兼容的问题修正，如 `1.0.0` → `1.0.1`

## 4. 命名规则应用场景

### 4.1 开发阶段
- **推荐状态**：`dev`、`alpha`、`debug`
- **命名示例**：
  - `Loop_dev_1.1.0_20260326_01.apk`
  - `Loop_alpha_0.9.0_20260326_01.apk`

### 4.2 测试阶段
- **推荐状态**：`beta`、`rc`
- **命名示例**：
  - `Loop_beta_1.0.0_20260326_01.apk`
  - `Loop_rc_1.0.0_20260326_01.apk`

### 4.3 发布阶段
- **推荐状态**：`release`
- **命名示例**：
  - `Loop_release_1.0.0_20260326_01.apk`

### 4.4 维护阶段
- **推荐状态**：`fix`、`hotfix`
- **命名示例**：
  - `Loop_fix_1.0.0_20260326_01.apk`
  - `Loop_hotfix_1.0.0_20260326_01.apk`

## 5. 最佳实践

### 5.1 版本发布流程
```
dev → alpha → beta → rc → release
```

### 5.2 问题修复流程
```
发现问题 → hotfix/fix → 测试 → release
```

### 5.3 功能迭代流程
```
dev → feature → alpha → beta → rc → release
```

## 6. 状态类型对照表

| 英文标识 | 中文名称 | 完整性 | 优先级 |
|---------|---------|--------|--------|
| release | 正式版 | ✅ 完全体 | 最高 |
| rc | 候选版 | ✅ 接近完全体 | 高 |
| fix | 修复版 | ✅ 完全体 | 高 |
| hotfix | 紧急修复版 | ✅ 完全体 | 最高 |
| beta | 测试版 | ⚠️ 非完全体 | 中 |
| feature | 功能版 | ⚠️ 非完全体 | 中 |
| alpha | 内测版 | ❌ 非完全体 | 低 |
| dev | 开发版 | ❌ 非完全体 | 低 |
| debug | 调试版 | ❌ 非完全体 | 低 |
