#### PDF 课表格式分析（已验证）

> 样本文件: `docs/PDF/王喆课表.pdf`
> 解析工具: pdfplumber (Python)
> 解析结果: 表格结构清晰，可直接提取
> [IMPORTANT] 缺少教室信息，不作为首选导入方式

**PDF 表格结构**:

```
表头行: [学期信息 + 姓名 + 学号]
列标题: [节次, (空), 星期一, 星期二, 星期三, 星期四, 星期五, 星期六, 星期日]
行结构: [上/下午/晚上, 节次编号(一二三四五), 课程1, 课程2, ...课程7]
尾注行: [注--内容顺序为：课程<>周次 打印时间]
```

**单元格格式规律**:

```
{课程名称}/({起始节}-{结束节}节){起始周}-{结束周}周[,{起始周}-{结束周}周...]

示例:
JAVA程序设计/(1-2节)2-5周,7-9周,11-19周
计算机网络基础/(1-2节)2-9周,11-12周
职业通用英语1-2/2-3周
高等数学1-2/2-8周,10-15周,17-19周
```

**解析要点**:
- 课程名称与周次之间用 `/` 分隔
- 周次支持多个区间，用逗号分隔（如 `2-5周,7-9周,11-19周`）
- 同一单元格可能包含多门课程（不同周次），用换行符分隔
- 部分课程包含节次信息（如 `(5-6节)`），表示跨节次上课
- 星期六/星期日也可能有课程
- [IMPORTANT] 不包含教室和教师信息
