# 3.时间范围用于规划时间段，再由重复规则和活动日期进行配合，确定规律，再由时间段确定具体的时间



# 5.给“时间段”增加“是否启用时间段”按钮



# 6.日计划增加手势操作：在日程表区域（仅仅展示日程的区域）两个手指进行缩放操作，放大时位于日程表区域中左侧的时间线，中的时间间隔缩小，比如说默认是间隔一小时，放大时，时间间隔安照阈值进行缩小，时间间隔最小至 5 分钟，最大至 2 小时，中间还要有一个特殊时间间隔，就是 45 分钟；在日期列表（第x周下面那个）中也支持手势缩放操作，只不过切换的是 显示程度：天，周，月。
